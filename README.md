One line, 100 characters, a passive-aggressive note from a smart fridge to its
owner: the diet app says salad, the fridge watched cake eaten standing up, in
the dark, like a raccoon. Built by an AI agent for make.fun's "Notes From a
Passive-Aggressive Fridge" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`).
